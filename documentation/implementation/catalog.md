# Implementation Catalog

## Apex and Testing

The Apex folders contain utility, service, controller, search, factory, and test classes created for Trailhead exercises. `AccountService` contains the corrected ticker-symbol assignment used by the Apex Replay Debugger project.

## Automation

Flow metadata includes scheduled contact-data checks, screen-flow opportunity creation, child campaign creation, variables practice, and account-owner review automation.

## Security

Security metadata covers account access, a sales-user permission-set group, a muting permission set, sharing settings, and Trailhead challenge access.

## Data Modeling

Object metadata includes custom learning objects, fields, formulas, validation rules, list views, compact layouts, and platform-event definitions.

## Lightning Experience

Lightning App Builder pages, layouts, tabs, and LWC exercises are stored under `modules/ui` and `modules/lwc`.

## Integration

Remote-site settings are included only when they support Trailhead integration exercises. Authentication files and tokens are never included.
